# EFER AI Keyboard Shortcuts

| Shortcut | Scope | Action |
| --- | --- | --- |
| `Ctrl + K` / `Cmd + K` | Global | Clear and focus the message composer (returns to General Chat if viewing a roadmap screen) |
| `Enter` | Composer | Send the current message |
| `Shift + Enter` | Composer | Insert a new line without sending |
| `Ctrl + Enter` / `Cmd + Enter` | Global | Force send the current message |
| `Esc` | Menus & Drawers | Close open mobile drawer, attachment menu, or shortcuts popover |
